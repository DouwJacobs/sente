Initial optional Sente starter pack, using portable format version 2.

Includes 21 generic expense/income categories, five spending groups and four global fallback rules. Contains no personal EFT patterns, account names, credentials or transactions.

Use Settings → Configuration to pull, validate, preview and import. Updates are manual. Pin `v1.0.0` or its commit for repeatable imports. Requires Sente's portable configuration workflow; the application implementation is being prepared on `codex/portable-configuration`.

Public repository fetching and the full import were verified with isolated synthetic data. Schema and authoring instructions are included in this repository.
